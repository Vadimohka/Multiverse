# Единый конвейер мониторинга депозитов

## Что происходит автоматически

Один workflow `Универсальный парсер источников` является общим парсером всех источников проекта `Мониторинг депозитов и ставок банков Беларуси`.

Для каждого сайта он создаёт отдельный запуск, забирает страницу, извлекает подтверждённые условия, нормализует поля и сохраняет их в единый dataset `Депозиты банков Беларуси`. Поэтому ошибка одного сайта не останавливает остальные и видна в его собственном run.

Схема: **Источники → общий workflow → отдельные runs по сайтам → dataset → проверка → Excel / API**.

## Запустить всё сейчас

1. Откройте **Workflows** и выберите `Универсальный парсер источников`.
2. Нажмите **Опубликовать**, если меняли настройки или промпт.
3. Нажмите **Запустить**.
4. Выберите **Запустить все публичные источники**.
5. Откройте **Запуски**: здесь будет отдельная строка на каждый источник. `WAITING_FOR_REVIEW` означает, что строки получены и ожидают проверки; `FAILED` означает, что надо открыть строку и посмотреть узел с ошибкой.
6. Откройте **Проверка данных** и подтвердите новые или изменённые предложения. После подтверждения они станут видны в экспорте.
7. Для финансовых условий включите в **Данные → Редактировать dataset** параметр **«Контрольная выборка неизменных записей за запуск»** (рекомендуется 3–5). После каждого запуска сервис создаст столько задач «Контрольная выборка»: откройте `source_url`/raw artifact, сверьте ставку, срок и валюту, затем нажмите **Сверено**. **Не совпадает** только фиксирует проблему и не удаляет данные из выгрузки; **Исправить** создаёт исправленную версию записи.

Источники с состоянием `Нужен доступ` не попадают в общий запуск: сервис не подставляет для них данные. После получения разрешённого доступа измените состояние в **Источники → Статус доступа** на `Публичный доступ`.

## Управление источниками

1. Откройте **Источники** и выберите проект в фильтре.
2. Нажмите **Добавить URL**: Source Profiler проверит страницу и предложит режим загрузки. Создаётся только источник, а не отдельный workflow.
3. Нажмите на строку источника, чтобы изменить URL, режим загрузки, описание или снять флаг **Использовать в общем запуске**.
4. В таблице сразу видно, какие источники публичны, требуют доступ и участвуют в запуске. Универсальный workflow при следующем запуске автоматически видит все включённые публичные источники проекта.

## Забрать Excel

1. Откройте **Данные**.
2. Dataset выбирается автоматически. На экране видны счётчики подтверждённых и ожидающих строк, а вкладка **Все собранные** показывает оба типа записей.
3. После выборочной проверки начального среза нажмите **Принять базовый срез**. Подтверждаются только первые версии записей; будущие изменения останутся в очереди проверки.
4. Нажмите **XLSX**. Файл содержит только подтверждённые записи со ссылкой `source_url` и временем наблюдения `observed_at`.

## Забрать по API

Авторизованный запрос на текущие записи:

```text
GET /api/v1/datasets/1dcfd00f-7265-4859-b52b-4453b18a3a32/records
```

Экспорт XLSX по API:

```text
POST /api/v1/exports
Content-Type: application/json

{"dataset_id":"1dcfd00f-7265-4859-b52b-4453b18a3a32","format":"xlsx"}
```

## Включить еженедельный сбор

1. В workflow щёлкните по пустому месту canvas, чтобы открыть настройки workflow.
2. Отметьте **Расписание запускает все публичные источники проекта**.
3. Нажмите **Сохранить draft**, затем **Опубликовать**.
4. Откройте **Расписания** и создайте расписание для этого workflow: `0 8 * * 1`, timezone `Europe/Minsk`.

Так запуск произойдёт каждый понедельник в 08:00 по Минску. Ручной запуск остаётся доступен для внеплановой проверки рынка.
